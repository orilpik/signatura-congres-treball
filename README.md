# Signatura de correu · II Congrés Català del Treball

Pàgina pública per generar i copiar la signatura de correu del II Congrés Català del Treball (1, 2 i 3 de desembre de 2026, TecnoCampus Mataró).

- **Pàgina:** https://orilpik.github.io/signatura-congres-treball/
- `index.html`: formulari (nom, càrrec, telèfon, correu), previsualització i botó «Copia la signatura».
- `signatura-compacta.html`: la signatura en HTML amb marcadors, per si algú prefereix editar-la a mà.
- `logo-congres.png`, `organitzen.png` (i `@2x`): imatges que carreguen les signatures. **No les moveu ni les reanomeneu**: totes les signatures instal·lades hi apunten.

Quan es conegui el web del congrés, cal posar-lo a la variable `WEB` de `index.html`.
